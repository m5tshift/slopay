# SLOPay

Crypto payment gateway: a merchant issues an invoice in USD, the buyer pays in ETH, the merchant receives a signed webhook once the payment is confirmed on chain.

Event-driven microservices on Kubernetes: Kafka, PostgreSQL, MongoDB, ClickHouse, Valkey, Istio, Argo CD.

- Requirements specification (in Russian): [docs/SRS.md](docs/SRS.md)
- GitOps repository: [slopay-gitops](https://github.com/m5tshift/slopay-gitops)

> Test networks only (local Anvil, optionally Sepolia). No mainnet, no real funds.
